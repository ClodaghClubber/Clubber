Fixture Creation — Field Mapping Spec

Maps county board fixture data to the Clubber Create Fixture API
● Auto-mapped ● Fixed default ● Lookup file ● Leave blank
Grade field: County board competition names contain grade info (e.g. "Senior Football Championship") but the mapping to Clubber's grade values (Senior 1 / Senior 2 / Intermediate 1 etc.) is ambiguous — we can't reliably distinguish Senior 1 from Senior 2 from the board name alone. Leave Grade blank unless Clubber can confirm the correct value per competition, or the API allows it to be omitted.
Reference files
Club lookup
club-lookup.json
Maps board club name → clubberId (UUID) and canonical Clubber name, keyed by county. 472 clubs, 472/472 resolved.
Competition lookup
competitionLookup.json
Clubber's own competition list. Each county maps to a GAA competition entry by preferredCounty. Use routeName as the competition identifier.
Fixture data source
Worker API response
Each fixture object exposes: county, sport, grade, teamA, teamB, date, time, venue.
Competition
Form field Source Value / Logic Notes
scope Fixed default "Club" Always Club for county board fixtures.
sport Fixed default "GAA" Always GAA.
code Auto-mapped fixture.sport Worker value is lowercase — capitalise first letter. "hurling" → "Hurling", "football" → "Football". Allowed values: Hurling, Football, Camogie, LGFA.
competition Lookup file competitionLookup.json Find the GAA sport entry, then find the competition where preferredCounty === fixture.county. Use that entry's routeName as the competition identifier (e.g. Cork → "cork", Kerry → "kerry").
season Fixed default "Season 26" All fixtures are 2026 season.
grade Leave blank — See notice above. Raw value from fixture.grade is available if Clubber can define the mapping later. Partial guidance below.
round Leave blank — Not reliably available from county board data.

Teams
Form field Source Value / Logic Notes
county Auto-mapped fixture.county County of Team A. e.g. "Cork"
v county Auto-mapped fixture.county Same as county — both clubs are from the same county board. Each club's Clubber record independently carries its county association, so cross-county fixtures (if they arise) will resolve correctly via the club ID.
club Lookup file club-lookup.json Look up club-lookup.json[county][fixture.teamA].clubberId — returns Clubber UUID. Pass UUID to API.
v club Lookup file club-lookup.json Same as above using fixture.teamB.
